# 小牧场日记 — MCP 工具下载/安装清单

> 链接存活状态于 2026-10-13 实测。
> **重要认知**：这 6 个 MCP server 里只有 1 个需要真正"下载"。
> 其余全是 stdio server，写进 MCP 客户端配置后，客户端用 `npx` / `uvx` / `pip` 自己拉。
> 手动下 zip 反而会把自己坑死（路径、依赖、更新全要自己管）。

---

## 0. 前置依赖（不装这两个，后面全白搭）

| # | 东西 | 链接 | 安装动作 |
|---|---|---|---|
| 0.1 | **uv** | <https://docs.astral.sh/uv/getting-started/installation/> | `powershell -c "irm https://astral.sh/uv/install.ps1 \| iex"` |
| 0.2 | **Godot 4.7.2** | <https://godotengine.org/download/windows/> | 见下方 ⚠️ 警告 |

- `uv` 是 `lpc-character-mcp` 的硬依赖（它的官方安装方式就是 `uvx`）。本机实测缺失。
- Godot 本机也缺失。

### ⚠️ Godot 下载的坑（本机特有）

`npx godot-mcp-enhanced install` 会从 **GitHub Releases** 拉 Godot 二进制并做 SHA512 校验。
**但本机 `github.com` 的 HTTPS 长期不稳**（TLS 握手间歇被 RST），实测 `releases/tag/4.7.2-stable` 页面直接超时。

**方案 A（推荐，先试）**：
```powershell
npx godot-mcp-enhanced install
```
能跑通就万事大吉。

**方案 B（A 失败时）**：手动下载 Godot，再让 MCP 认它。
```powershell
# 1. 浏览器打开官方下载页，下 Windows 版 Standard（不要 .NET 版）
#    https://godotengine.org/download/windows/
# 2. 解压到固定位置，例如 C:\Godot\
# 3. 让 godot-mcp-enhanced 认这个二进制
$env:GODOT_MCP_ALLOWED_GODOT_PATHS = "C:\Godot"
# 4. 验证
npx godot-mcp-enhanced doctor
```

**方案 C（A、B 都失败，走国内镜像）**：
- 中文官网：<https://www.godotengine.net.cn/>
- GodotHub 社区：<https://godothub.com/zh>

## 6. 实测的链接异常说明

| 现象 | 真相 |
|---|---|
| npmjs.com 返回 **403** | npm 官网挡爬虫 UA，**不是死链**。包确实存在（已通过 registry API 验证） |
| `aistudio.google.com` 连不上 | 本机网络问题，链接本身有效。手机上打开没问题 |
| `github.com/.../releases/...` 超时 | 本机 GitHub HTTPS 间歇被 RST，见 §0 的 ⚠️ |

## 7. 最短路径（照抄）

```powershell
# ① 前置
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

# ② Godot（失败则走方案 B/C）
npx godot-mcp-enhanced install

# ③ 验证
npx godot-mcp-enhanced doctor

# ④ LPC 素材定义
uvx lpc-character-mcp --setup

# ⑤ 地块工具
pip install ssyubix-pixelart-mcp

# ⑥ 把 _uu\mcp-config.json 并进客户端配置，填两个 Key，重开终端
```

或直接跑我写好的幂等脚本：
```powershell
powershell -ExecutionPolicy Bypass -File "D:\UU的办公室\小牧场日记\_uu\安装MCP环境.ps1"
```
