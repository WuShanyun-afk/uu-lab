## 二、玩法（游戏内）

| 操作 | 键 |
|---|---|
| 移动 | `WASD` / 方向键 |
| 锄头 / 洒水壶 / 种子 | `1` `2` `3` |
| **饲料** | `4` |
| **手（挤奶 / 捡蛋 / 抚摸）** | `5` |
| 使用 | `E` 或鼠标左键 |
| **全屏切换** | `F11` |

- **牧场**在右侧木栅栏里（牛 ×2、鸡 ×3）。
- 走到动物**面前**（面朝方向 46 像素内）按 `E`：
  - 拿**饲料**（工具 4）→ 喂食，好感 **+10**，扣 1 份干草饲料。
  - 拿**手**（工具 5）→ 有产出就**挤奶 / 捡蛋**入背包；没产出就**抚摸**（+5，每天 2 次）。
- **奶牛只能在 6:00–9:00 挤奶**（游戏内 06:00 开场，前 3 个游戏小时）。过了窗口按手会提示「现在挤不出奶」。
- **鸡蛋随时可捡**（GDD：鸡不挑时间）。
- 底部提示条会在空手站在动物旁时显示「名字 / 心数 / 状态（饿·可收·生病）」。

## 三、架构取舍（重要，别踩）

**逻辑层与渲染层彻底切开，和 FarmGrid / FarmLayer 同一套哲学：**

```
AnimalState（纯逻辑，RefCounted）   ← 可 headless 断言，零节点依赖
        ↑ 只读
AnimalNode（渲染，Node2D）          ← 素材到位只重写这一个文件
```

- `AnimalNode` 会自动找 `assets/sprites/animals/<species>_32.png`；**有真素材就用，没有就 `_draw()` 占位**。
  所以以后 Pollinations 出了牛的行走图，往那个路径一扔就换好了，逻辑一行不动。
- 幼年动物（`days_old < mature_days`）= **70% 缩放**（GDD §3.2），已在渲染层实现。

## 四、数值实现对照（GDD §3）

| 项 | GDD | 实现 |
|---|---|---|
| 好感 0–10 心 | 1 心 = 100 点 | `affection / 100`，满值 1000 |
| 喂食 | +10 / 次，按 feed_freq | 奶牛 2 次、鸡 1 次 |
| 抚摸 | +5，每天 2 次 | ✅ |
| 刷毛 | +8，每天 1 次 | ✅ |
| 抱抱 | +6，家禽专属 | ✅ 奶牛返回 false |
| 漏喂 | -15 / 餐 | `missed × 15` |
| 生病 | 好感<3 心 且 连续漏喂≥2 天，15%/天 | ✅（200 次内必触发，已测） |
| 品质 | 6 心银星 / 9 心金星 | `_roll_quality()` |
| 低好感不产出 | 0–2 心 10% 概率 | ✅ |
| 高好感特殊产出 | 奶牛≥8 心大罐牛奶；鸡≥8 心金蛋 15% | `product_high` + `high_chance` |

**产品变体用数据表驱动，不在代码里 if 物种：**

```
id,name,kind,price,product,product_min,product_max,product_high,high_chance,feed_freq,mature_days,timed
cow,奶牛,livestock,800,milk,1,2,milk_large,0.0,2,7,1
chicken,鸡,poultry,200,egg,1,1,gold_egg,0.15,1,3,0
```

加山羊（里程碑 7）= 加一行 CSV，代码不用动。

## 六、踩坑记录

1. **测试写错，不是逻辑错**（3 项）：
   - 「漏 1 餐 -15」：`feed()` 先给了 +10，基准应从喂食后算。→ 先喂再重置 affection。
   - 「3 只动物都产出」：0–2 心有 **10% 概率不产出**，3 只里有一两只不出是正常的。
     → 测试里把好感拉高到 5 心再断言。
   **教训：断言里不能带概率事件，除非把概率拉成 0 或 1。**
2. `AnimalLayer` 要加 `class_name`，否则 `@onready var x: Node2D` 上调自定义方法类型不安全。
3. `.bat` 里带中文路径必须存 **GBK**，UTF-8 会被 cmd.exe 按 GBK 读成乱码。
