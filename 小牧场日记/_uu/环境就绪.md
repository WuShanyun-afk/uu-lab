## 零、网络真相（本次最重要的发现）

**你的 VPN 一直在开，但它是「代理模式」，不是全局 TUN。**

| `myip.ipip.net` | 240e:45a:... **中国安徽合肥电信** ← 这条没走代理 |
| 网卡列表 | 只有 WLAN，**没有任何 TUN/TAP 虚拟网卡** |

### 为什么之前全线失败

**命令行工具不读 Windows 系统代理。** 这是 Windows 上一个经典陷阱：

| 工具 | 读系统代理？ | 读 `HTTP_PROXY` 环境变量？ |
|---|---|---|
| 浏览器 | ✅ 读 | — |
| PowerShell `Invoke-WebRequest` | ✅ 读 | ✅ |
| **`curl.exe`** | ❌ **不读** | ✅ |
| **Python `urllib` / `requests`** | ❌ **不读** | ✅ |
| **`npm` / `pip` / `uv`** | 部分 | ✅ |

所以我之前所有的 `curl`、`python` 调用**全都在裸奔**——浏览器能上 Google，我的终端上不去。这解释了之前所有诡异现象。

### 修法

已写入**用户级环境变量**（对所有新开进程生效）：

```
HTTP_PROXY  = http://127.0.0.1:7892
HTTPS_PROXY = http://127.0.0.1:7892
NO_PROXY    = localhost,127.0.0.1,::1,registry.npmmirror.com,
              pypi.tuna.tsinghua.edu.cn,mirrors.aliyun.com,registry.npmjs.org
```

`NO_PROXY` 里放国内镜像，让它们走直连，不浪费代理流量。

| 目标 | 修之前 | 修之后 |
|---|---|---|
| GitHub Release 下载 | **0 字节，连接被 RST** | ✅ 3MB / 8 秒 |

| Pollinations 生图 | **HTTP 402 限流** | ✅ HTTP 200 |

**结论：Google 全家桶现在是通的。你那两个免费 Key 值得重新去申请。**
