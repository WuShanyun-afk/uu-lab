## 2. 分层（和项目其它模块同一套哲学）

```
                      ┌─────────────────────────────┐
   EventBus 事件 ───▶  │  AudioManager（autoload 节点）│  ──▶  AudioServer 总线
   直接调用 ─────────▶ │  只负责「按分配结果 play()」  │        Master / BGM / SFX / Amb
                      └──────┬───────────────┬──────┘
                             │               │
                    ┌────────▼──────┐  ┌─────▼──────────┐
                    │  SfxPool      │  │  BgmDirector   │
                    │  纯逻辑：闸门  │  │  纯函数：选曲   │
                    │  （可 headless）│  │  （可 headless）│
                    └───────────────┘  └────────────────┘
                             │
                    ┌────────▼────────┐
                    │  AudioDB + CSV  │  35 条定义：路径 / 类别 / 音量 / 抖动 / 冷却 / 循环
                    └─────────────────┘
```

为什么要拆三个文件：

- **`BgmDirector`**：选曲规则要能被测试**逐格断言**（4 时段 × 5 天气 × 4 季节 × 5 场景里真正会出现的那几十种），
  写成纯函数就能钉死，而不是「听着差不多」。
- **`SfxPool`**：音效最容易出的两个 bug 都是**分配问题**（爆音 = 同帧叠十几声；吃音 = 长音独占唯一通道），
  这两条不需要真出声就能验证。
- **`AudioManager`**：剩下的容器活（建总线、建播放器、订阅事件、读写配置、淡入淡出）。

## 3. AudioManager 关键 API

| API | 用途 |
|---|---|
| `play_sfx(id, opts)` | 普通音效（内部走冷却 / 并发 / 抢槽三条闸门） |
| `play_sfx_at(id, world_pos)` | 有方位的音效（动物叫 / 建造落点）：音量随距离衰减 + 左右声像 |
| `play_ui(id)` | UI 音（语义入口，以后接 UI 总线 / 静音开关只改这里） |
| `play_bgm(id, fade=-1)` | 换 BGM，两路播放器交叉淡入淡出；`fade<0` 用策划给的时长 |
| `stop_bgm(fade)` | 停 BGM |
| `refresh_bgm()` | 按「时段 / 天气 / 季节 / 场景」重算该放哪首（事件里都调这个） |
| `footstep(pos)` | 走一步：根据注册的地表查询选草地 / 泥地 / 木地板 |
| `set_terrain_provider(cb)` | main 注册「世界坐标 → 地表」；房间场景注册恒为木地板 |
| `set_volume(bus, v)` / `get_volume(bus)` | 四条总线线性音量（0–1），改完立即写 `user://audio_settings.cfg` |
| `stats()` | 调试面板用：当前曲 / 环境音 / 池占用 / 拦截计数 / 音量 / 缺素材数 |
| `reset_state()` | 测试用：清池、停一切、清统计（不动总线与设置） |

**三条闸门**（`SfxPool.try_acquire`，按顺序）：

1. **冷却**：同一 id 距上次播放 < `def.cooldown` → 拒。金币连爆就是被它压住的（0.06s）。
2. **同 id 并发**：已响着 `def.max_voices` 个 → 拒。牛叫不会二重唱。
3. **槽位**：优先空闲槽；12 个全忙就**抢最早该结束的那个**（`steal`）——
   切掉一个快播完的音，比完全不播新音听感损失小。

另外每个槽带**代数 token**：被抢掉的旧音效的 `finished` 回调不能误释放新音效。

## 4. 音频数据表 `data/audio.csv`

| 列 | 说明 |
|---|---|
| `id` | 逻辑名（代码里只用它，不写文件路径） |
| `kind` | `sfx` / `ambience` / `bgm` |
| `file` | `res://audio/...`（素材换了只改这一列） |
| `category` | `step` / `interact` / `animal` / `ui` / `system` / `amb` / `bgm` |
| `volume` | 线性音量（每条独立，和总线音量相乘） |
| `pitch_min` / `pitch_max` | 每次播放随机音高（±8%），避免机械化 |
| `cooldown` | 同 id 最小间隔（秒） |
| `max_voices` | 同 id 最大并发 |
| `loop` | 是否循环（BGM / 雨声为 true） |

清单：**27 音效**（脚步 3 / 交互 7 / 动物 9 / 界面 4 / 系统 4）+ **1 雨声** + **7 BGM**。

## 5. 动态 BGM（`BgmDirector.choose`）

优先级从高到低：

| 顺序 | 条件 | 曲目 |
|---|---|---|
| ① | 室内场景（house / shop / mine） | `bgm_indoor` —— 外面下刀子里面也是暖的 |
| ② | 雨 / 雷雨 | `bgm_rain` —— 忧郁小调 + 雨声层（需求 3 点名的） |
| ③ | 雪 / 暴风雪 | `bgm_snow` |
| ④ | 冬季的清晨 / 白天 | `bgm_snow`（晴天也要有冬天的味道） |
| ⑤ | 时段 | 清晨 `bgm_morning` / 白天 `bgm_day` / 黄昏 `bgm_dusk` / 夜晚 `bgm_night` |

换曲淡入时长：天气切换 2.6s（更慢，免得吵）、进出室内 1.8s、时段切换 1.2s。
雨声环境音独立一路：下雨时淡入，进屋**不关**而是压到 45%（隔着一层屋顶）。

## 6. 各模块接入示例（这轮实际改的）

### 6.1 脚步（player.gd）

```gdscript
# _ready：2D 音效需要监听者，挂在玩家身上（牧场 / 房间共用 player.tscn）
var listener := AudioListener2D.new()
add_child(listener)
listener.make_current()

# _physics_process：走一步发一个事件，按「走的时间」节流，不按帧
_step_timer -= delta
if _step_timer <= 0.0:
    _step_timer = STEP_INTERVAL          # 0.34s
    EventBus.player_stepped.emit(global_position)
```

### 6.2 交互音（main.gd）

```gdscript
if tilled > 0:
    _player.play_hoe()
    AudioManager.play_sfx(&"hoe")        # 锄地

if n > 0:
    _player.play_watering()
    AudioManager.play_sfx(&"water")      # 浇水

_grid.plant(cell, id)
AudioManager.play_sfx(&"plant")          # 播种

GameState.add_item(item, cnt)
AudioManager.play_sfx(_harvest_sfx(a.species))   # cow/goat→milk, sheep/alpaca→shears, 其余→egg
```

### 6.3 跨系统事件（EventBus，不用改玩法代码）

```gdscript

EventBus.gold_changed.emit(n, gold)      # AudioManager → coin（只响入账）

# AudioManager 订阅

EventBus.animal_vocalized → animal_<species>     # 2D 池，带距离衰减
EventBus.player_stepped   → footstep(pos)
EventBus.room_prop_used   → save 音（存档柜）
EventBus.building_placed  → build_place
```

### 6.4 房间（room_scene.gd）


## 7. 素材：程序化生成（`_uu/gen_audio.py`）

- 纯 numpy + `wave`，固定随机种子 → **连续两次运行 35 个文件 SHA256 完全一致**；
- 44100Hz / 16-bit：SFX 单声道、BGM 立体声（声部轻微左右 pan）；
- 峰值：SFX −6 dBFS、雨声 −9 dBFS、BGM −12 dBFS；DC 偏置用 22Hz 一阶高通去掉；
- 无缝循环：BGM 按整小节合成、尾音**环形绕回**开头叠加；雨声 4.000s 环形；
- 自检内建：帧数 / 采样率 / 位深 / 声道 / 循环接缝（seam ≤ 0.002 / 相邻样本差 ratio ≤ 0.061）/ 无 NaN / 无静音尾巴。

**已知偏差（诚实说明）**：

- 总体积 **31.7 MB**（30.34 MB 是 7 首 BGM 的 PCM 本身）。想压到 7 MB 可把 BGM 转 Ogg Vorbis，
  但那样 `data/audio.csv` 的 `file` 列要改成 `.ogg`、`AudioStreamWAV` 的循环兜底逻辑对 Ogg 不适用
  （Ogg 用 `loop` 属性）——这一轮先按「WAV / 16-bit」契约交付。
- BPM 为「整小节」微调（如 morning 104→100），换来循环点落在小节线上，听感差异很小。
- `bgm_morning` 的 RMS 比 indoor 低约 4.5 dB（鼓瞬态顶高峰值）。嫌小就改
  `_uu/gen_audio.py` 里 morning 的 `drums amp 0.26→0.20` 重跑。

## 10. 踩过的坑

1. **`EventBus.scene_entered` 是死信号**：真正的换场信号在 `SceneRouter.scene_entered` 上。
   音频系统一开始连了 EventBus 那个，结果**进屋不换 BGM**（日志里 `bgm=bgm_dusk`、面板却写「室内」）。
   已删掉死信号并加断言防回归。
2. **WAV 默认导入成 QOA 压缩流**（`compress/mode=2`）：`loop_end` 不能用 `data.size()/2` 算字节，
   必须用 `get_length() * mix_rate` 换算帧，否则 BGM 循环点错位、听着像跳针。
3. **`AudioStreamPlayer2D` 需要 `AudioListener2D`**：没有监听者时 2D 音效要么不响要么位置全错。
   把监听者挂在玩家身上（`player.tscn` 牧场 / 房间共用），走到哪听到哪。
4. **`--script` 模式没有 autoload**：`godot --headless --script x.gd` 里 `AudioManager` 直接未定义，
   探针必须做成场景跑。
5. **headless 的音频驱动是 dummy**：断言只能测「分配 / 状态 / 信号」，不能测「真的听见了」；
   `playing` 不可靠，别拿它当断言依据。
6. **`ui_modal` 已经把背包 / 商店 / 存档面板全覆盖**：本来想加 `inventory_toggled` 信号，
   结果会和 `ui_modal_changed` 重复（同帧两声被冷却拦掉，看似能跑但语义混乱）——删掉。
7. **`--headless --import` 不一定一次成功**：上一轮测试进程没退干净时导入会半途而废
   （`.import` 一个都没生成）。重新导入一次并数 `.import` 文件数量即可确认。
8. **脚步按时间不按帧**：按帧算的话 144Hz 显示器上脚步声会密一倍。
9. **AI 生成素材要留「可重跑」**：脚本固定种子 + 内置自检，换素材 / 调音色都是改参数重跑，
   而不是手动修 35 个文件。
