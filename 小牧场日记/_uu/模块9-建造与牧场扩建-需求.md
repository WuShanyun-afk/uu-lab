## 3. 计划的数据结构（明天动手前先定死）

```
BuildingDef（CSV 一行 → Resource 壳，真源仍在 data/buildings.csv）
  id, name, category, size(Tiles), price, material, material_count,
  upgrade_price_base, capacity_base, capacity_per_level, efficiency,
  stage_required, note

PlacedBuilding（RefCounted，一栋已落地建筑）
  def_id, cell(Vector2i), level, built_day, origin(左上角), footprint(Array[Vector2i])

BuildingGrid（RefCounted 纯逻辑，不碰节点）
  placed: Dictionary[cell] -> PlacedBuilding
  can_place(def_id, cell) -> StringName 枚举（OK / OUT_OF_BOUNDS / OCCUPIED / NO_STAGE / NEED_WATER? ...）
  place(def_id, cell) -> bool
  remove(cell) -> Dictionary（返还材料）
  footprint_of(def_id, cell) -> Array[Vector2i]
  to_dict / from_dict（存档）
```

**规矩沿用前八个模块的**：规则（纯逻辑）与表现（节点 / UI）切开，headless 可断言；返回值用枚举不用 bool。

## 4. 放置 / 拆除的设计口径

- 网格 32px 吸附；鼠标/面前格子为目标；不压围栏、不压农田、不压动物栏、不出地图边界。
- 放置流程：进入「建造模式」（买地/选图 → 幽灵预览：绿=可放，红=不可放 + 原因文字）→ 确认扣钱扣木材 → 落地。
- 拆除：返还 50% 材料（GDD §6），建筑内的东西（加工槽 / 动物）先迁移或提示。
- 碰撞：每栋落地建筑生成 `StaticBody2D`（参考 `WorldCollision` 同一份矩形，画面与碰撞同源）。
