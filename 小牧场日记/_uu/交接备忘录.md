**跑挂了的三个常见原因**（按概率排）：

1. **GDScript 解析错误** → 测试场景根本不会走到 `quit()`，命令一直挂着。看到「超时 / 不返回」先找 `Parse Error`，
   别怀疑测试逻辑。常见根因：`var x := <Variant 表达式>`（GDScript 把警告当错误）。
2. **`PYTHONIOENCODING` 没设** → `run_tests.py` 在处理失败分支时 `print` 撞 gbk 编码，抛 `UnicodeEncodeError`。
3. **旧的 Godot 进程占着终端** → `--import` 或测试被上一次没退干净的进程拖住；先 `Get-Process | ? ProcessName -like '*odot*'` 清掉。

## 3. 架构速查（看不懂主线代码时先看这张）

### 3.1 三层结构（全项目统一）

```
纯逻辑层（RefCounted / 不碰节点）  ← headless 可断言，测试主要打这里
       ↓
数据层（CSV + autoload DB）
       ↓
表现层（Node / Node2D / Control，只读逻辑层，不持有玩法真值）
```

例：`FarmGrid`（逻辑）→ `FarmLayer`（画）· `Herd`/`AnimalState`（逻辑）→ `AnimalNode`（画）·
`SfxPool`/`BgmDirector`（逻辑）→ `AudioManager`（播）。

### 3.2 19 个 autoload（顺序有讲究，见 `project.godot`）

```
EventBus → GameClock → WeatherSystem → [7 个 DB] → GameState → SceneRouter
→ SavePanel → HouseDB → DayCycle → AudioDB → AudioManager → AudioDebugPanel
```

- **GameState / GameClock / WeatherSystem**：全局状态，任何场景都活着，存档直接灌它们。
- **SceneRouter**：唯一知道「现在在哪个场景」的地方，`carry` 揣着牧场那一局的完整存档跨场景。
- **DayCycle**：睡觉推进 + 2:00 昏倒罚金。
- **AudioManager**：所有声音的唯一入口。

### 3.3 数据流：牧场那一局在哪

**农场 / 牧群 / 建筑 / 订单 / 加工槽 / 施工队列的真值都在 `scripts/main.gd` 的成员变量里**
（`_grid` `_herd` `_builds` `_sites` `_orders` `_proc`）。离开牧场时 `main._build_save()` 打成一包
交给 `SceneRouter.carry`，回来时 `take_carry()` 灌回去。房间场景（小屋/小镇/商店/矿洞）**没有农场数据**，
只读全局 autoload。

### 3.4 存档

- 格式 **JSON v4**，17 段（clock/weather/state/farm/herd/orders/processor/player/buildings/npcs/story/construction/scene/meta…），见 `scripts/save/save_system.gd` 顶部注释。
- 槽位：0 自动（跨日）/ 1 快速（F5）/ 2–5 手动（F6 面板）。
- 原子写：`.tmp` → 校验长度 → 旧档挪 `.bak` → 改名。
- `migrate()` **只加不改**：加新段就在里面补默认值，绝不动老键。

### 3.5 场景切换

`get_tree().change_scene_to_file()` 的**唯一调用点**是 `SceneRouter._change_scene()`。
5 个场景：`farm / house / town / shop / mine`（后 4 个共用一个 `RoomScene` 脚本 + `RoomData` 表）。

### 3.6 时间

- 1 游戏天 = `TOTAL_MINUTES`（2:00 凌晨自动睡），10 游戏分钟 = 1 tick。
- 时段：`phase_at(minutes)` —— **<180 清晨 / <660 白天 / <840 黄昏 / 其余夜晚**（6:00 为 0）。
- ⚠️ 老注释里写「6:00–9:00」是**人类作息**的说法，代码里是 `minutes`（相对 6:00 的偏移），
  写测试时别照注释算：`minutes=60` 是 07:00，`minutes=900` 是 21:00。

## 5. 这台机器的坑（不看会浪费一晚上）

1. **`.bat` 必须 UTF-8 + CRLF，且全 ASCII**。cmd.exe 按 UTF-8 读 bat，写中文/GBK 会「找不到路径」；
   LF-only 会被解析错位；`chcp 65001` 写在中间会让读取偏移错乱。`.gitattributes` 已锁行尾。
2. **github HTTPS 间歇性掐断**，只走 SSH。
3. **`git push` 成功也会返回 exit code 1**（PowerShell 把 stderr 当错误）。
   看输出里的 `旧..新  main -> main` 那行才算成功。
4. **`--script` 模式没有 autoload**：`godot --headless --script x.gd` 里 `GameState` / `AudioManager`
   全是未定义。探针必须做成 `.tscn` 场景跑。
5. **新 `class_name` 脚本要先 `--headless --import` 一次**，否则 `SceneRouter` 之类引用它的脚本报找不到类型。
6. **`--headless --import` 会偶发半途而废**（上一轮进程没退干净时）。数一下 `.import` 文件数量确认。
7. **音频在 headless 下是 dummy 驱动**：能测分配/状态/信号，不能测「真的听见了」。
8. **WAV 默认导入成 QOA 压缩流**：`AudioStreamWAV.loop_end` 必须用 `get_length() * mix_rate` 换算，别用 `data.size()`。
9. **GDScript 的几个硬规则**：lambda 按值捕获局部变量（计数器放字典/数组）；`bool("字符串")` 是运行时错误；
   `var x := <Variant>` 是解析错误（要显式标注类型）；`Vector2` 没有 `.end`。
10. **中文路径**：`git -c core.quotepath=false` 才能看清中文文件名；PowerShell 偶尔把中文路径输出成乱码，
    用 `[System.IO.Directory]::GetDirectories()` 之类的 .NET API 更稳。
11. **`_uu/*.log` 不要提交**：`git add -A` 之后记得 `git reset -q _uu/*.log`。
    注意 `~$*.docx` 那类 Office 锁文件也可能被 `git add -A` 扫进去（本次已重置）。

## 8. 工作方式约定（继续这个项目请照做）

1. **一个模块 = 一轮交付**：数据结构 + 代码 + 测试 + 截图 + 文档 + commit/push，缺一不可。
2. **文档写在 `小牧场日记/_uu/模块N-xxx.md`**，固定七节：需求对照 / 数据结构 / 流程图 /
   关键设计（为什么这么做）/ 踩坑 / 文件清单 / 还没做的。
3. **注释写「为什么」不写「是什么」**：解释取舍、踩过的坑、为什么不用另一条路。这个仓库一直是这个风格。
4. **commit message 格式**：
   `小牧场日记：模块N —— 标题（要点 · 要点，N 套 M 项断言全绿）`
5. **每次加测试套件都要在 `_uu/run_tests.py` 的 `SUITES` 里注册**，否则全量跑不到。
6. **改动跨模块行为时，同步更新旧测试并在测试里写注释说明为什么改**（例：模块 12 让建造要许可证后，
   模块 9 的测试必须跟着改；模块 11 的床从「弹对话」变成「睡觉推进次日」）。
7. **别破坏分层**：纯逻辑不放节点、CSV 不加「只在一处用一次的列」、UI 不持有玩法真值。
8. **截图脚本的驱动节点挂在 `get_tree().root` 上**（换场会把 `current_scene` free 掉），
   并且**不要 `queue_free()` 自己**——用 `change_scene_to_file.call_deferred()` 进牧场，
   否则第一张截图是空白图（模块 11 复验时踩过）。
