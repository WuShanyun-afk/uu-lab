## 一、你刚才那个报错是什么

```
McpError : Request failed: FormatException:
Scheme not starting with alphabetic character (at character 1)
{  "_comment": "澞敖墩駒拱櫺?…
              ↑
```

**两个错叠一起了：**

### 错 1：粘错地方了

Kelivo 的 MCP 服务器有**三种传输方式**：Streamable HTTP / SSE / **STDIO**。
你新建的那条默认是 **HTTP**，然后把整个 JSON 粘进了 **URL 字段**。

Kelivo 就去按网址解析 `{  "_comment": ...` —— 开头是个 `{`，不是 `http`，
所以 Dart 的 `Uri.parse` 报「Scheme 不是字母开头」。

> 我从 Kelivo 数据库里挖出了你那条记录：
> ```
> id        = de5f8f01-6261-4a8e-b2aa-0737e78bada0
> transport = "http"
> url       = "{  \"_comment\": \"…"      ← 就是这里
> ```
> **这条要删掉。** 它 enabled=true，不删会一直报错。

### 错 2：中文乱码（我的锅）

`澞敖墩駒拱櫺?` 是「小牧场日记」被 **UTF-8 当 GBK 读**的结果。

根因：PowerShell 5.1 的 `Get-Content -Raw` **默认按 GBK 解码**，而我那个 bat 没写
`-Encoding UTF8`。剪贴板里就塞进了乱码。

**已修**，新版 bat 加了 `-Encoding UTF8`，实测剪贴板中文正确。

## 二、正确的导入姿势

### 一键版

双击：

```
D:\UU的办公室\一键配置MCP.bat
```

它会：
1. 把 **`_uu\mcp-import.json`**（干净版）复制到剪贴板 —— UTF-8 已修正；
2. 打开文件所在文件夹。

### 然后你在 Kelivo 里点

```
设置 → MCP → 添加服务器 → 找「JSON 导入」→ 粘贴 → 保存
```

> 官方手册原话：「在「设置 → MCP」里添加服务器。传输可以是 Streamable HTTP、SSE 或
> STDIO。HTTP 类要填地址，STDIO 要填命令。需要登录的服务器走 OAuth。**也可以用 JSON 导入。**」

**顺序别搞反：**

1. **先删掉那条错的**（名字叫 `MCP`、transport = http 的）。
2. 再走上面的 JSON 导入。
3. **完全退出 Kelivo 再打开**（任务栏右键退出，不是点 ×）。

### 手填版（万一找不到「JSON 导入」按钮）

一条一条加，每条都选 **STDIO**，只填「命令」和「参数」：

| 名称 | 传输 | 命令 | 参数 |
|---|---|---|---|
| godot | STDIO | `C:\Users\32265\AppData\Local\Programs\nodejs\npx.cmd` | `-y` `godot-mcp-enhanced` |
| pixelart | STDIO | `C:\Users\32265\.local\bin\uvx.exe` | `ssyubix-pixelart-mcp` |
| lpc | STDIO | `C:\Users\32265\.local\bin\uvx.exe` | `lpc-character-mcp` |

环境变量如果界面能填，照 `mcp-import.json` 抄；填不了也行——用户级
`HTTP_PROXY` / `HTTPS_PROXY` 已经写进注册表了，**只要 Kelivo 是重启后启动的**就能继承。

## 四、启动慢的真相

第一次跑 godot 探针花了 **46.6 秒**，第二次 **1.6 秒**。

不是配置问题，是 **npx 第一次要把 `godot-mcp-enhanced` 下载到本地缓存**。
缓存之后就是 1.6 秒。

> 所以：**如果你在 Kelivo 里第一次连 godot 超时，别慌，等它下载完，再点一次连接。**

## 五、全屏 —— 为什么一定是满的

**你的显示器是 1920×1080**（我实测了）。游戏内部画布 640×360，3 倍整数缩放：

```
640 × 3 = 1920   ✅
360 × 3 = 1080   ✅
```

横竖都整除 → **全屏 100% 铺满、零黑边、零模糊**。

- 双击 `运行牧场(全屏).bat` → 直接全屏
- 游戏里按 **`F11`** → 随时切换
