## 二、场景树结构

```
Main (Node2D, main.gd)                    ← 总控：时间/光照/HUD/交互提示
├── World (Node2D)
│   ├── GroundLayer (TileMapLayer, z=-1)  ← 草地真素材，24×14 格
│   ├── FarmLayer (Node2D)
│   │   ├── SoilLayer (TileMapLayer)      ← 耕地（土壤）
│   │   └── CropLayer (Node2D)            ← 作物（必须在 SoilLayer 之后，否则被盖住）
│   ├── WorldCollision (StaticBody2D)     ← 4 面围墙 + 5 段栅栏（含 2 格门洞）
│   ├── SignPost (Area2D + CollisionShape2D, layer 2)      ← 告示牌
│   ├── ShippingBin (Area2D + CollisionShape2D, layer 2)   ← 出货箱
│   └── YSortRoot (Node2D, y_sort_enabled)
│       ├── AnimalLayer (Node2D, y_sort)  ← 2 牛 3 鸡
│       └── Player (CharacterBody2D, player.gd)
│           ├── AnimatedSprite2D (64×64 帧, 上移 32px 对齐脚底)
│           ├── CollisionShape2D (20×10 脚部碰撞盒)
│           ├── InteractProbe (Area2D, mask=2)   ← 扫可交互物
│           │   └── ProbeShape (CircleShape2D r=44)
│           └── Camera2D (平滑跟随, limit 0,0 → 768,448)
├── CanvasModulate                          ← 昼夜光照
└── UI (CanvasLayer)
    ├── HUD (Label)      左上：日期/时间/金币/工具/动物/背包
    ├── Prompt (Label)   底部居中：「E  看告示牌」
    └── Tip (Label)      最底：一次性消息（收获/出货/浇水）
```

**碰撞层约定**

| 层 | 用途 | 谁在 |
|---|---|---|
| 1 | 物理阻挡 | `WorldCollision`、玩家 |
| 2 | 可交互 | `Interactable` 及其子类 |

玩家探针 `collision_mask = 2`，只扫可交互物；可交互物 `monitoring = false`，只负责被扫到。

## 三、操作

| 键 | 作用 |
|---|---|
| `WASD` / 方向键 | 8 方向移动（斜向 = 8 向之一，立绘取主轴） |
| `E` / 鼠标左键 | 有可交互物 → 交互它；没有 → 用当前工具作用于面前格子 |
| `1`~`5` | 锄头 / 洒水壶 / 种子 / 饲料 / 手 |
| 鼠标滚轮 | 循环换工具（5 → 1 绕回） |
| `F11` | 全屏切换 |

牧场栅栏**左侧有一个 2 格门洞**，走进去才能喂牛；撞墙会被真实挡住。

## 四、怎么加一个新的可交互物（不用改 player.gd / main.gd）

```gdscript
class_name MyThing
extends Interactable

func _ready() -> void:
    super()
    prompt_text = "看东西"

func prompt() -> String:
    return "E  看东西（%d 件）" % GameState.count_item(&"turnip")

func interact(player: Node) -> void:
    EventBus.world_message.emit("看到了")
```

场景里挂一个 `Area2D` + `CollisionShape2D` 就行，探针会自动扫到它。

## 六、踩过的坑（都写进代码注释了）

1. **LPC 素材会「0 字节静默失败」**。`lpc-character-mcp` 的 `_download()` 一旦 urlopen
   抛异常就写一个空文件占位，而且因为 `if not local.exists()` **永不重试**。
   结果：女性 body / head / 发型的 `walk.png` 全是 0 字节 → 渲染直接报
   `no layers found for this combination`。
   修：`_uu/lpc_prefetch.py`（按官方文件清单整段重拉，源顺序 ghfast.top → gh-proxy.com → jsDelivr）。
   **另一个坑中坑**：判断「要不要走代理」时别用 `"raw.githubusercontent" in url` ——
   ghfast.top 的 URL 里也含这段，会把请求塞给没启动的 `127.0.0.1:7892`，报 `WinError 10061`。
2. **地图尺寸以前有两份**（`main.gd` 的 `PEN` 和 `ground_layer.gd` 的 `FIELD_TILES`/`PEN`），
   改一处就穿模。现在统一到 `WorldConfig`，**画面和碰撞用同一组矩形**，不可能出现
   「看着有栅栏、实际能穿过去」。
3. **8 向移动 + 4 向立绘**：LPC 素材只有 4 向，所以逻辑朝向存 `facing8`（8 向，交互点用它），
   立绘朝向 `facing` 取主轴。斜着走用主轴那张图，这是标准做法。
