## 🐄 小牧场日记（Godot 4.7）

我自己写的牧场经营游戏。GDD 定稿在 `小牧场日记/gdd-小牧场日记.md`（61 节 / 363 行表格）。

### 怎么开

| 双击这个 | 干什么 |
| --- | --- |
| `运行牧场.bat` | 窗口模式（640×360，整数倍放大） |
| `运行牧场(全屏).bat` | 全屏。1920×1080 正好是 640×360 的 **3 倍**，零黑边零模糊 |
| 游戏里按 `F11` | 随时窗口 / 全屏切换 |

启动脚本会自动找 Godot（先翻 `PATH`，再翻 `%USERPROFILE%\.godot-mcp\godot\`），找不到会给提示。
根目录那两个 bat 只是**转发**，真逻辑在 `小牧场日记/` 里，而且是**纯 ASCII**——
这台机器的 `cmd.exe` 按 UTF-8 解析 `.bat`，往里写中文或换成 GBK 都会炸（详见下面的坑）。

### 这台机器上踩过的坑

- **`.bat` 必须是 UTF-8 + CRLF**。cmd.exe 按 UTF-8 读 bat（即使 ACP=936），
  所以 GBK 编码的 bat 会「找不到路径」；LF-only 的 bat 会被解析错位（`call` 被拆成 `ca` + `ll`）。
  另外 `chcp 65001` 写在文件中间会让 cmd 的读取偏移错乱 —— 结论：**别写 chcp，全 ASCII 最安全**。
- `GameState.advance_day()` 是**全局**语义。写测试时不能在同一格里先浇水测复活、再测枯死。
- 地块**绝不能用 AI 生图**（31×33 的裂缝），走确定性像素绘制。
