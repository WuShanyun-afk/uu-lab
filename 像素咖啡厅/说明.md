## 怎么玩

**一句话：客人头上会冒出气泡，气泡里就是 TA 点的东西，做出来送过去。**

### 🖱️ 懒人玩法（推荐先这么玩）

**直接点客人就行**，就这一个动作：

- 出杯口正好有 TA 要的那杯 → 立刻送过去，钱和小费到手 😻
- 没有 → **自动帮你照单开工**（扣原料、占咖啡机），做好了再点一次 TA 就送走

全程只需要点客人。谁点了什么，气泡上看一眼就知道。

### 🎛️ 手动玩法（想自己排兵布阵再用）

1. 看客人头顶的**气泡**：里面画着要什么咖啡、几号杯、热的还是冰的
   - 左边那个杯子 = 咖啡种类（马克杯是热饮，带吸管的透明杯是冰饮）
   - 右边三个小方块 = 杯型，亮几个就是几号杯（小 / 中 / 大）
   - 下面那根彩色条 = **耐心**，绿 → 黄 → 红，红了就快走了
2. 在下面选好**杯型**和**冷热**（默认中杯热饮，不改最省事）
3. 点下面那排**咖啡按钮**开始做，机器会自己出杯，做好的杯子落到**出杯口**
4. **点客人**，对得上的那杯就送过去了

> 提前把常点的几杯做好堆在出杯口，客人一来就送 —— 这样小费最高。

**小费看耐心**：客人等得越短，小费越多（最多 +8）。

**出杯口只有 3 格**，做错了或者堆满了就点那个杯子把它倒掉。

### 📖 菜单 / 配方页

右上角点 **「📖 菜单」**，随时能看：

- 现在手上每样原料还剩多少
- **每一款咖啡要扣什么**（豆 / 奶 / 糖浆 / 纸杯，各要几个）
- 每款的价格和出杯时间
- **「还能做几杯」** —— 按最紧的那样原料算，缺料会直接写「原料不够」
- 没解锁的会写 🔒 和价格

打开菜单的时候**游戏会自动暂停**，看完了关掉继续。点旁边空白处也能关。

## 一些技术上的小脾气

- 画面**只有 320×180 像素**，靠 `image-rendering: pixelated` 放大，是货真价实的像素画。
- 但**显示尺寸不是写死的**：打开时按窗口算，**能凑整数倍就凑整数倍**（320×180 → 640×360 → 960×540 → 1280×720），凑不上就按比例铺满可用空间。1080p 的屏上就是 **4 倍，1280×720**；2K 屏能到 6 倍。
- 右上角 **⛶ 放大** 是全屏开关，窗口一改尺寸画面就自己重算。
- 屏幕太小？**手机横过来玩**：横屏时控制面板会收成右侧**抽屉**（顶栏点 **⚙ 面板** 拉出来，点一下画面就收回去），画面直接吃满整块屏幕 —— 844×390 的机器上能到 **619×348**，比竖屏大三倍多。
- 整张画面**只用 `fillRect` 画**——没有任何路径、渐变、贴图。天空的"渐变"是两段色带加一行抖动（dither）拼出来的，这才叫像素风。
- 猫咪是 14×14 的点阵，写成一行行字符串存在 `SPR` 里，**换一套颜色就是另一只猫**。
- 音效全部用 **Web Audio 现场合成**，零音频文件（机器声是带通滤波的白噪声，收银是方波）。
- **存档在浏览器本地**（`localStorage`），打烊时自动存，下次打开接着开。
- 窗外天空会跟着游戏时间变：早上蓝 → 正午亮 → 黄昏橙 → 夜里紫 + 星星。

## 开发者的话

游戏脚本最后导出了一个 `window.PixelCafe` 接口，可以在控制台里调试：

```js
PixelCafe.G.money = 9999        // 直接改钱
PixelCafe.G.lv.machine = 3      // 咖啡机拉满
PixelCafe.G.stock.bean = 999    // 豆子管够
PixelCafe.startBrew(PixelCafe.DRINKS[1], 2, 1)   // 直接做一杯大杯冰拿铁
```
